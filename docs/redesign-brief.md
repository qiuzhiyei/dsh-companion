## 1. 产品是什么（30 秒背景）

**DSH 伴侣**是 DeepSeek Harness（DSH，一个 AI 编程桌面应用）的第三方伴侣插件，MIT 开源，本地运行。它做三件事：

1. **桌面宠物**：一只鲸鱼娘角色常驻桌面（Electron 透明置顶悬浮窗），随 AI 任务状态切换表情动作（待机/思考/干活/完成/出错…），可抚摸、拖拽、逗彩蛋；
2. **用量统计**：记录每个 AI 任务的 Token/费用/时长/工具调用，提供统计面板（今日/周/月/全部、图表、排行、历史明细、CSV/JSON 导出）；
3. **监控告警**：预算超限、余额不足、久坐提醒，通过桌宠气泡 + 系统 Toast 通知。

用户画像：开发者（DSH 用户），长时间盯着 IDE，桌宠是「陪伴感 + 信息仪表盘」的混合体。

## 2. 为什么重设计

现有视觉是开发过程中逐步长出来的「工程师审美」：深色科技蓝、六色 tone 系统、emoji 当图标、毛玻璃顶栏。功能上没问题，但整体观感**廉价、风格不统一、没有记忆点**。用户（产品所有者）的原话：「整体设计风格都丑」。期望通过专业设计重做，达到**商业产品级的完成度和统一的视觉语言**。

## 3. 现状盘点（旧设计的完整清单）

### 3.1 统计面板（核心界面）

- **容器**：1100×760 模态大窗（嵌在宿主 GUI 里，iframe 加载），内容区 max-width 1180px
- **配色**：深色 `#141b23` 底 / `#1a242f` 卡片 / `#293745` 边框 / `#dbe7f2` 主文字 / `#8aa0b5` 次文字 / 强调蓝 `#4f8cff` / 金色 `#ffd766`（金额、高亮）
- **浅色主题**：`prefers-color-scheme: light` 媒体查询整段覆盖
- **字体**：Segoe UI / Microsoft YaHei，14px 基准；数字用 `tabular-nums`
- **结构**：
  - 吸顶毛玻璃顶栏（logo + 标题 + 实时状态）+ 胶囊页签导航
  - 4 个页签：**历史任务**（筛选工具栏 + 表格 + 分页）/ **统计**（KPI 卡网格 + 柱状图 + 排行榜）/ **会话**（DSH 会话列表 + 批量删除）/ **设置**（左栏分组导航 + 卡片网格）
  - KPI 卡：左侧 3px 竖色条 + 圆角图标块（emoji）+ 大数字 + 环比涨跌
  - 六色 tone 系统：blue `#4f8cff` / green `#37b26c` / violet `#9a6cff` / gold `#e0a23a` / cyan `#39c5d8` / teal `#2fa89a`
  - 设置页：左栏 4 个分组（🧸 伴侣 / 🍅 提醒 / 💰 计费 / 📦 数据，emoji 当图标），共 9 张卡：伴侣外观（含皮肤选择/不透明度/缩放/点击穿透/隐私模式/随 DSH 启动等开关）/ 久坐提醒 / 预算告警 / 余额台账 / 货币 / 模型计价 / 操作（暂停/导出 CSV·JSON）/ 数据保留 / 事件模拟（mock 模式才显示）
  - 图表：手绘内联 SVG 柱状图（hover tooltip、当前时段金色高亮柱）
  - 组件：胶囊分段控件（seg）、开关（switch）、下拉、数字输入、ⓘ 悬浮提示、骨架屏、toast、确认浮条

### 3.2 GUI 侧边栏角标

- 宿主侧边栏底部的一行小卡：🤖 emoji + 单行大字（任务中显示实时 token + 呼吸状态点；空闲显示「今日 xx token」）+ hover tooltip
- 点击弹出上述面板大窗
- 颜色走宿主的 `--dsw-alias-*` CSS 变量（带回退值），**必须能融入宿主明暗两套皮肤**

### 3.3 桌宠悬浮窗 HUD

- 宠物本体：220×200 CSS px 显示区（图片 object-fit: contain），窗口整体透明悬浮在桌面上
- **状态气泡**（宠物下方）：深色玻璃 `rgba(20,28,38,.88)` 圆角 12px，两行截断；变体：普通 / alert（橙红边+深红底）/ done-ok（绿边）/ done-bad（红边）；内含久坐提醒的两个小按钮（起来走走 / 稍后 10 分钟）
- **余额举牌**（双击宠物时弹出，宠物上方）：184px 深色玻璃小黑板 + 底部小三角箭头 + 金色大金额，带 pop 入场动画
- 交互动画：CSS transform（挤压/摇晃/张望/伸懒腰/打瞌睡/走路颠），emoji 粒子（❤✨💫☕）
- **关键约束：悬浮在任意桌面壁纸上，必须保证可读性**（这也是为什么现在全是深色玻璃）

### 3.4 桌宠形象素材（AI 生图，非 HTML）

- 角色：Q 版鲸鱼娘，二头身 chibi，蓝色短发 + 头顶鲸鱼背鳍 + 鲸鱼尾巴，DeepSeek 品牌拟人化
- **5 套服装 = 5 种人格**：JK 学院风（默认，元气）/ 秘书 OL（总裁腔）/ 女警（御姐干练）/ 中华娘（古风娴静）/ 旗袍（优雅傲娇）
- 每套 12 帧 PNG：8 状态帧（待机/启动/思考/干活/收尾/完成/出错/中断）+ 4 反应帧（被摸舒服/生气/晕头/被拎起）
- 规格：≥1024×1024 正方形、透明背景、全套统一裁剪框（状态切换不跳）、图内不带投影

### 3.5 插件图标 + 托盘

- icon.svg：64×64 viewBox 原创 SVG（深色圆角底 + 白色团子宠物 + 绿色状态点），≤256KiB，要在 16~48px 下清晰
- 托盘菜单是系统原生（无需设计），但托盘小图标需要单色可辨识版本

## 5. 硬性工程约束（不可协商，违反即返工）

1. **纯 HTML + CSS，零框架零依赖**：不用 Tailwind/Bootstrap/图标库/Google Fonts。图标一律内联 SVG 或 emoji；字体只用系统栈（Segoe UI / Microsoft YaHei / -apple-system）
2. **所有颜色/圆角/阴影/间距必须定义为 CSS 变量**（design token 化），集中放在 `:root`——接入方要按 token 表重构，不是硬编码搬运
3. **明暗双主题**：深色为默认，浅色经 `prefers-color-scheme: light` 覆盖（只换 token 值，不重写布局）
4. **保留现有 DOM 结构约定**：JS 通过 id/class/data 属性接线（`data-tab`、`.set-card`、`#bubble`、`.kpi` 等）。重设计可以改样式、改布局、改组件外观，但**给出的 HTML 里同类元素要有清晰稳定的命名钩子**，并附「旧选择器 → 新选择器」映射表
5. **面板响应式**：1100×760 模态内为主场景，同时 640px 窄宽不破版（现有断点 1020/980/760/640 可参考）
6. **数字排版**：统计数字必须 `font-variant-numeric: tabular-nums`，大数字+小单位的层级关系保留
7. **桌宠 HUD**：透明窗口内渲染，任何背景（深色壁纸/白色网页/花色桌面）上都要可读；气泡最多两行截断的排版要保留；举牌金额是视觉焦点
8. **角标**：颜色尽量走 `var(--dsw-alias-*, 回退值)` 模式，保证在宿主明暗皮肤里都协调
9. **图标**：单文件 SVG，viewBox 64×64，≤256KiB，16px 下仍可辨识；托盘版本单色
10. **动效克制**：过渡 0.15~0.3s，尊重 `prefers-reduced-motion`；现有骨架屏 shimmer、呼吸点、举牌 pop 这类功能性动效保留但可重新设计

## 6. 交付要求（重点：先方向后细化）

### 6.1 第一轮（本次）：3 个完整风格方向

每个方向必须包含：

1. **方向命名 + 一段设计理念**（为什么适合这个产品：开发者工具 × 桌面陪伴 × 数据仪表盘）
2. **Design token 表**：色板（底/卡/边框/文字 4 级/强调色/语义色 成功·警告·错误·金额）+ 圆角 + 阴影 + 间距刻度 + 字体字号阶梯——**直接写成 CSS 变量代码块**（`--bg-base: #xxx;` 这种可复制形态），不要只给色卡图
3. **统计页整页**：KPI 卡网格（≥6 张，含环比涨跌）+ 柱状图卡（含当前时段高亮柱、hover tooltip）+ 排行榜（模型/项目两组）+ 余额条带
4. **设置页**：左栏分组导航 + 一张代表卡片（含开关 switch / 数字输入 / 下拉 / ⓘ 悬浮提示 / 危险操作按钮）
5. **桌宠 HUD**：气泡 4 个变体（普通 / 告警 alert / 成功 done-ok / 失败 done-bad）+ 余额举牌（placard）+ 久坐提醒按钮组。**可读性验证方式**：在同一个 HTML 里用 CSS 铺三块模拟壁纸背景（深色纯色调 / 浅色纯色调 / 高对比花色渐变），把 HUD 组件分别摆上去展示——因为交付物是 HTML 而非效果图，用 CSS 背景模拟即可，不需要真实截图
6. **GUI 侧边栏角标**：深色宿主、浅色宿主各一版，含「任务中（呼吸点 + 实时 token）」与「空闲（今日 token）」两种状态
7. **插件图标**：64×64 viewBox 的 SVG **源码**（不是位图）+ 托盘用单色版 SVG 源码
8. **桌宠形象素材 art direction**：该方向下鲸鱼娘的画风定义（渲染方式 / 线条 / 色板 / 光影 / 与 UI 的呼应关系）+ 1 个状态帧（建议 `idle`）的完整生图提示词示例（中英双版）

### 6.2 格式硬性要求（⚠ 最重要，违反即不可用）

1. **必须是可读源码，不接受只给效果图/截图**。接入方要按你的输出重构现有工程代码
2. 第 3~6 项**每个方向合并成一个单文件 HTML**（一个方向一个文件，命名如 `direction-a.html`），CSS 全部内联在 `<style>` 里，**浏览器双击直接打开就能完整预览**，不依赖任何本地文件或网络
3. **所有颜色/圆角/阴影/间距/字号必须走 `:root` CSS 变量**，组件里只引用变量名，不出现裸色值（接入方按 token 表重构，硬编码等于没做 token 化）
4. **零外部依赖**：不引 Tailwind / Bootstrap / 任何图标库 / Google Fonts；图标一律内联 SVG 或 emoji；字体只用系统栈（`"Segoe UI", "Microsoft YaHei", -apple-system, sans-serif`）
5. **明暗双主题**：默认深色为完整实现，浅色用 `@media (prefers-color-scheme: light)` **只覆盖 token 值**，不重写任何布局规则
6. **HTML 里保留清晰稳定的 class/id 命名钩子**（如 `.kpi` `.set-card` `#bubble` `.chart-card`），因为现有 JS 通过这些选择器接线；命名可重新设计，但要成体系、可预测
7. 图标 SVG 给**源码文本**，不要 base64、不要图片链接
8. 最后附一份**三方向对比表**：各自气质定位 / 最适合的使用场景 / 实现成本，以及**你推荐哪个 + 理由**（产品所有者会参考你的判断）

### 6.3 第二轮（选定方向后）：全量细化

按选定方向输出：全部 4 页签（历史任务 / 统计 / 会话 / 设置）的完整 HTML/CSS、全部 9 张设置卡、全部组件的完整交互态（default/hover/active/focus/disabled/error/loading/empty）、明暗两套 token 的完整取值表、**旧选择器 → 新选择器映射表**（见第 5 节约束 4）。

### 6.4 如果你无法输出代码

至少必须给全这三样，缺一不可（否则接入方无法还原）：

1. 高保真效果图（明暗双主题、全部 4 页签、桌宠 HUD 在深色/浅色/花色三种壁纸背景上的可读性展示）
2. **完整 token 表的具体数值**（每个色值的 hex、每级圆角/间距/字号的 px 值、阴影的完整参数）——不能只说「柔和的圆角」这种描述
3. 图标 SVG 源码

## 8. 明确不要的

- 不要拟物/重插画风背景（面板是工具，信息密度优先）
- 不要纯黑 OLED 风（现有深色是蓝灰调，纯黑会显廉价——除非方向刻意如此并说明理由）
- 不要动布局信息架构的**功能**（页签划分、设置分组是功能决策，视觉可重排但功能不减）
- 不要在图内带文字水印；不要外部图片链接（预览图除外）
- 桌宠形象不要改成非鲸鱼娘的其他角色（IP 已定，只调画风）
